# Hướng dẫn sử dụng DotMan

Hướng dẫn cài đặt và sử dụng các tính năng của **DotMan (Donation Manager)**.

- Mọi cấu hình đều nằm trong các file `.yml` của thư mục `plugins/DotMan`.
- Tính năng chỉ có ở bản Premium được đánh dấu <Badge type="tip" text="Premium" />.

## Công cụ hỗ trợ

Một số cấu hình dài và dễ sai, nên DotMan có sẵn công cụ chạy ngay trên trình duyệt:

- [Tính toán point](/docs/cong-cu/tinh-toan-point): Xem trước số point người chơi nhận được.
- [Tạo và kiểm tra lịch khuyến mãi](/docs/cong-cu/lich-khuyen-mai): Tạo mới khuyến mãi hoặc dán file có sẵn để tìm lỗi.
- [Tạo placeholder](/docs/cong-cu/tao-placeholder): Chọn loại dữ liệu để ra đúng placeholder.
- [Thiết kế Discord Embed](/docs/cong-cu/thiet-ke-discord-embed): Chuyển thiết kế Discohook thành `discord.yml`.
- [Tạo mốc nạp và thưởng top](/docs/cong-cu/moc-nap-va-thuong-top): Tạo mốc nạp, mốc nạp tổng và phần thưởng top.

## Dùng hướng dẫn hiệu quả

- Dùng ô **Tìm kiếm** trên thanh menu để tìm nhanh một tính năng hoặc tên key trong cấu hình.
- Mỗi trang có nút **Sao chép Markdown** và **Mở bằng AI** cạnh tiêu đề, tiện khi muốn hỏi thêm về nội dung trang.
- Trang [Config mẫu](/docs/config-mau/config-yml) là nội dung file cấu hình mặc định của plugin, dùng để đối chiếu khi cấu hình hoặc cập nhật.

## Cần hỗ trợ

- Tham gia [Discord MineVN Studio](https://minevn.net/studio) để được hỗ trợ cài đặt và sử dụng.
- Với bản miễn phí, bạn có thể báo lỗi hoặc đóng góp trên [GitHub](https://github.com/minevn/dotman).
