# Tạo placeholder

Chọn loại dữ liệu, khoảng thời gian và hạng để tạo placeholder dùng với PlaceholderAPI. Bật **Tạo danh sách** để ra sẵn nhiều dòng top cho hologram, scoreboard.

Giải thích chi tiết từng placeholder xem tại [Placeholder API](/tham-khao/placeholder-api).
