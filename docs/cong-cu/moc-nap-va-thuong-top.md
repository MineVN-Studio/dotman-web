# Tạo mốc nạp & thưởng top

Tạo nội dung cho 3 file bằng form, không cần nhớ cú pháp YAML:

| Thẻ | File | Hướng dẫn |
|-----|------|-----------|
| Mốc nạp cá nhân | `mocnap.yml` | [Mốc nạp cá nhân](/phan-thuong/moc-nap-ca-nhan) |
| Mốc nạp tổng server | `mocnaptong.yml` | [Mốc nạp tổng server](/phan-thuong/moc-nap-tong) |
| Phần thưởng top nạp <Badge type="tip" text="Premium" /> | `phanthuongtop.yml` | [Phần thưởng top nạp](/phan-thuong/phan-thuong-top) |

- Có thể nhập file đang có để sửa tiếp, ở mục **Nhập từ file** cuối trang.
- Công cụ cảnh báo các lỗi thường gặp: số tiền không hợp lệ, ID khung thời gian có dấu `_`, khoảng hạng trùng nhau, lệnh có dấu `/` ở đầu.
